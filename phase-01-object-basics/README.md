# Phase 1 — Object Basics (15 Exercises)

## 📖 Introduction

This phase is all about making object creation and property access feel
effortless. Once you finish it, later phases (especially arrays of objects)
become much easier because you won't have to think about object syntax anymore.

## 📌 Rules for Phase 1

**Allowed**

- ✅ Only use object syntax (`{}`)
- ✅ Use dot notation and bracket notation
- ✅ Use `console.log()`
- ✅ Use `delete`
- ✅ Add properties
- ✅ Modify properties
- ✅ Nested objects

**Not allowed**

- ❌ No arrays (except where explicitly introduced later)
- ❌ No loops
- ❌ No functions
- ❌ No `Object.keys()`, `Object.values()`, `Object.entries()`
- ❌ No destructuring
- ❌ No advanced object methods
