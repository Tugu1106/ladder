# Phase 2 — Array Fundamentals (20 Exercises)

Difficulty: ⭐☆☆☆☆ → ⭐⭐☆☆☆

## 📖 Introduction

This phase covers the core building blocks of arrays: creating them, accessing
elements, and the essential mutator methods (`push`, `pop`, `shift`, `unshift`,
`slice`, `splice`) plus looping through them.

## 📌 Rules

**Allowed**

✅ `[]` · ✅ index access · ✅ `.length` · ✅ `push` · ✅ `pop` · ✅ `shift` ·
✅ `unshift` · ✅ `slice` · ✅ `splice` · ✅ `for` loop · ✅ `for...of`

**Not allowed yet**

❌ `map()` · ❌ `filter()` · ❌ `reduce()` · ❌ `find()` · ❌ Object methods · ❌ DOM

## 🏁 Wrap-up

After this phase, you should be able to look at:

```javascript
const users = [{name:"John"},{name:"Jane"}];
```

and not be scared by the array part.

Then Phase 3 will combine your Phase 1 + Phase 2 skills: **Arrays of Objects** —
the thing you will use constantly in frontend/backend development. 🚀
