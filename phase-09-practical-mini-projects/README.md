# Phase 9 — Practical JavaScript Mini Projects (20 Projects)

## 📖 Introduction

Now we stop doing isolated exercises. You have trained: variables, functions,
objects, arrays, and array methods (`forEach`, `map`, `filter`, `reduce`). Now
you need to train **problem solving**.

Real programming is not "use map here, use filter there." Real programming is
"I have data. I need to transform it into useful information."

## 📌 Rules

For every project:

1. create the data yourself
2. write functions
3. process data
4. return useful results

**Allowed**

✅ functions · ✅ objects · ✅ arrays · ✅ `map` · ✅ `filter` · ✅ `reduce` ·
✅ loops if necessary

Goal: write clean JavaScript.

## 🏁 Phase 9 Completion Goal

When you finish these, you should be able to look at:

```javascript
[{ user:"Alex", orders:[] }]
```

and immediately think: "I need to filter users, map their orders, reduce totals,
maybe group data." That is the same thinking used in React applications, backend
APIs, database processing, dashboards, SaaS applications.

After Phase 9: 🔥 **Phase 10 should be DOM + JavaScript projects** — Todo App,
Calculator, Notes App, Weather App, Shopping Cart, Dashboard — because then you
combine your data skills with UI.
