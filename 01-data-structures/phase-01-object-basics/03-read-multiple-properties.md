# Exercise 3 — Read Multiple Properties

**Trains:** dot notation · multiple `console.log()` calls
**Difficulty:** 🟢 Easy

## What you're solving

Same skill as Exercise 2, but now you pull out two values instead of one. The
point is repetition until the syntax stops requiring thought.

## Starter data

```javascript
const person = { name: "Tugu", age: 22 };
```

Print the name and age on separate lines.

## Expected output

```javascript
Tugu
22
```

## Toolbox

- 🎯 **Focus:** dot notation twice · one `console.log()` per line
- ✅ **Allowed:** dot notation · multiple `console.log()`
- ❌ **Not allowed:** loops · `Object.values()` — printing two known keys by hand
  is the point; iterating over keys comes many phases later.

## Requirements

- Use dot notation for both
- Each value on its own line

## Hint

<details>
<summary>Show hint</summary>

Each `console.log()` call prints its own line. So two values on two lines means
two calls.

</details>
