# The Ladder 🪜

A zero-to-hero coding journey, built **by hand** — one new concept or tool per step.
Each folder is a stage; do them in order.

| # | Stage | What you learn |
| --- | --- | --- |
| **01** | [data-structures](./01-data-structures/) | JS fundamentals: objects, arrays, map/filter/reduce, real data challenges |
| **02** | [dom-and-events](./02-dom-and-events/) | The DOM: clicks, inputs, building interactive pages |
| **03** | [modern-js-for-react](./03-modern-js-for-react/) | Destructuring, spread, modules — the JS React leans on |
| **04** | [react](./04-react/) | Components, props, state, effects, lifting state, fetching APIs |
| **05** | [async-and-apis](./05-async-and-apis/) | Promises, async/await, `fetch` — calling live data |
| **06** | [backend](./06-backend/) | Node + Express: build your own API (routes, CRUD, structure) |

## How to use it

- Work top to bottom. Each stage assumes the ones before it.
- Everything is written by hand — the goal is problem-solving, not copy-paste.
- See [HANDBOOK.md](./HANDBOOK.md) for the build workflow and [ROADMAP.md](./ROADMAP.md)
  for what's ahead.
